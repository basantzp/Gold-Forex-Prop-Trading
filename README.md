## 🌟 Overview

**Gold Forex Prop Trading Master Roadmap** is a comprehensive, institutional-grade educational web platform and interactive roadmap designed specifically for mastering **XAU/USD (Gold)** trading and successfully passing proprietary trading firm challenges (**FTMO, FundedNext, MFF, Topstep, FundingPips, Funded Trading Plus**).

Faithfully transcribed and expanded from the authoritative 14-diagram master curriculum, this platform provides an interactive tree diagram (inspired by `roadmap.sh`), mathematical position size calculators, a live 24-hour intermarket session clock, an evaluation simulator, and a readiness assessment.

## ⚡ Interactive Built-in Features

1. **Interactive Visual Roadmap Tree**:
   - Central spine connecting all 24 master hubs and 168+ subtopic cards.
   - Click any node to open the institutional playbook drawer.
   - Interactive zoom & pan navigation with search filtering.

2. **XAU/USD Prop Risk & Lot Calculator**:
   - Computes exact lot sizing, dollar risk, pip values, margin requirements, and target levels based on challenge balance ($10k - $400k).
   - Real-time warning alerts if trade violates the prop firm 5% daily drawdown limit.

3. **Global Forex Session Radar**:
   - Live 24-hour UTC clock with active session indicators (Sydney, Tokyo, London, New York).
   - Automatically highlights the **Golden Window** (London/NY overlap from 12:00 to 16:00 UTC).

4. **Probabilistic Prop Challenge Simulator**:
   - Simulates sequences of trades with randomized outcomes to benchmark survival rates against daily and maximum loss rules.

5. **Prop Readiness Assessment Quiz**:
   - 10-question evaluation benchmark testing trader readiness on gold calculations and rule compliance.

6. **Local Progress Persistence & Certificate Generator**:
   - Progress is automatically saved to `localStorage`.
   - Export and import roadmap progress in JSON format.
   - Generate and print your official completion certificate.
